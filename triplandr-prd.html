01Обзор продукта

Triplandr — это платформа агрегации и фильтрации отзывов эмигрантов о странах и городах мира. Ключевое отличие от аналогов: все отзывы фильтруются по национальности читателя, потому что опыт украинца в Германии и опыт индийца в Германии — принципиально разные истории.

Ключевая идея: Украинец и индиец будут иметь совершенно разный опыт в Португалии — разные визовые требования, разное отношение местных, разные возможности для работы. Triplandr позволяет это увидеть.

Пользователи оставляют структурированные отзывы по 9 категориям, а система агрегирует их в рейтинги по стране и городу в разрезе национальности автора.

02Проблема

Существующие платформы (Numbeo, Expatistan, Expat Exchange) публикуют агрегированные данные без учёта национальности. Человек, планирующий переезд, получает усреднённую картину, которая может быть нерелевантна для его конкретной ситуации.

05Ключевые функции

Система отзывов

Отзыв состоит из структурированных оценок по 9 категориям (1–5 звёзд) и опциональных текстовых комментариев. Общая оценка вычисляется автоматически как среднее категориальных оценок (без поля "overall").

🛡️ ЛегализацияВизы, ВНЖ, процесс легализации
💰 Стоимость жизниАренда, еда, транспорт
🔒 БезопасностьКриминал, ощущение безопасности
📋 БюрократияДокументы, гос. услуги

Фильтрация по национальности

Выбранная национальность сохраняется в cookie nv_nationality и применяется на SSR. Пользователь может включить режим "показать все отзывы" без перезагрузки страницы.

Агрегация статистики

Таблицы country_stats и city_stats обновляются PostgreSQL-триггером при каждом INSERT или UPDATE отзыва. Хранят средние значения по каждой категории в разрезе национальности.

06User flow — написание отзыва

1
Выбор страны и национальности Пользователь указывает свою национальность и страну, о которой пишет
2
Заполнение категорий Оценки по звёздам и опциональные текстовые комментарии для каждой категории
3
Дополнительные детали Цель пребывания, город, климат, статус (ещё там / уже уехал)
4
Отправка → is_approved: false Отзыв сохраняется со статусом "на модерации", уведомление идёт в Telegram
5
Модерация в Telegram Администратор апрувит или отклоняет одной кнопкой
6
Публикация is_approved: true → триггер пересчитывает статистику → отзыв появляется на сайте

07Система модерации

Все новые отзывы проходят ручную модерацию через Telegram-бота.

Поток: Новый отзыв (INSERT) → PostgreSQL-триггер → Nuxt API route /api/webhook/review → Telegram-сообщение с кнопками → Нажатие кнопки → /api/webhook/telegram → UPDATE is_approved в Supabase
КомпонентОписание
on_review_insert_telegramPostgreSQL-триггер на INSERT в таблице reviews
/api/webhook/reviewПолучает данные из Supabase, отправляет сообщение в Telegram
/api/webhook/telegramПолучает callback от кнопок, обновляет is_approved через service_role key
SUPABASE_WEBHOOK_SECRETЗащита endpoint от несанкционированных запросов

Ключевые архитектурные решения

  • Nationality хранится в cookie nv_nationality — доступна на SSR без клиентского flash
  • Статистика преагрегирована в country_stats / city_stats — нет тяжёлых агрегатных запросов на чтение
  • City page: единый useAsyncData вместо cascade — устраняет race condition city → reviews
  • Рейтинг = среднее категориальных полей, исключая поле "overall" — консистентно во всех местах
